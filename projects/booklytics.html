BOOKLYTICS

A Python web scraping and data analysis project that extracts book information from Books to Scrape, cleans and structures the data, and presents meaningful insights through a Power BI dashboard.

Python BeautifulSoup Pandas Web Scraping Power BI
View on GitHub ↗

Project Overview

“Booklytics is an end-to-end data analytics project where I first scraped book data from the Book to Scrape website using Python and BeautifulSoup. I then used Pandas to clean and preprocess the data, including handling missing values and formatting the data. Finally, I used Power BI to create an interactive dashboard that provides insights into book prices, ratings, categories, and stock levels.”

Objective

  • To scrape book data from the Book to Scrape website using Python and BeautifulSoup
  • To clean and preprocess the data using Pandas for accurate analysis.
  • To analyze book prices, ratings, categories, and stock levels.
  • To identify useful patterns and trends across different book categories.
  • To create an interactive Power BI dashboard for clear visualization and data-driven insights.

Dataset

The data was collected from the Books to Scrape website. Approximately 50 pages were scraped and the extracted information was combined into a structured dataset.

Results & Insights

  • General Reading contains 152 books, making it the largest category, followed by Nonfiction with 110 books.
  • General Reading has 1,345 units in stock, the highest among all categories. Nonfiction follows with 975 units. This indicates these categories have the largest inventory levels.
  • Among the categories shown in the average-price chart, Suspense has the highest average price at $58.33, while New Adult has the lowest at $46.38.
  • Books with a 1-star rating account for 226 books, the highest rating group. In comparison, 5-star books account for 196 books. This suggests the dataset has a relatively large proportion of low-rated books.
  • Across all 1,000 books, the average price is $35.07 and the average rating is 2.92/5. This indicates that the overall collection has moderate pricing but relatively low average customer ratings.
