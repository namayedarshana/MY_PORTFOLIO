Calories Burn Prediction

A machine learning regression project that predicts calories burned during exercise using physical and activity-related features such as duration and heart rate.

Python Pandas NumPy Matplotlib Scikit-learn Streamlit Machine Learning
View GitHub

Project Overview

Calories Burn Prediction is a machine learning regression project developed to estimate the number of calories burned during physical activity.


The project uses exercise-related information such as duration and heart rate to train a regression model. A Streamlit application was created to allow users to enter values and receive a predicted calorie-burn result.

Objective

The main objective was to predict the number of calories burned during exercise based on features such as gender, age, height, weight, exercise duration, heart rate, and body temperature..

  • Understand the relationship between exercise variables and calories burned.
  • Clean and prepare the datasets for machine learning.
  • Perform exploratory data analysis.
  • Train a regression model.
  • Evaluate the model's predictions.
  • Deploy the model through Streamlit.

Dataset

The project uses two datasets containing exercise and calorie-related information. The datasets were combined and prepared for analysis and model training.

Project Workflow

01

Data Collection

Imported the exercise and calorie datasets required for the prediction task and merge both together.

02

Data Cleaning

Checked the datasets and prepared the required columns for analysis and machine learning.

03

Exploratory Analysis

Used Python libraries to understand relationships between exercise variables and calories burned, and perform Encoding and Scaling.

04

Model Training

Built a regression model using Scikit-learn to predict calorie expenditure. Among 9 compared models , Random forest as selected.

05

Streamlit Deployment

Created an interactive Streamlit application where users can enter exercise information and obtain a prediction.

▶️ How to Open and Run the Project

Step 1: Open Visual Studio Code

Open Visual Studio Code on your computer..

Step 2: Open the Project Folder

1.Click File → Open Folder
2.Select the Calories Burn Prediction project folder.
3.Click Select Folder.

Step 3: Open the Terminal

In VS Code:
Click Terminal → New Terminal
Make sure the terminal is opened inside the project folder.

Step 4: Install Required Libraries

Run: pip install -r requirements.txt
This will install all the Python libraries required for the project.

Step 5: Run the Streamlit Application

python -m streamlit run app.py
After running the command, Streamlit will provide a local URL, usually: http://localhost:8501

Disclaimer

This application provides an estimated calorie-burn prediction based on patterns learned from the training dataset. The prediction should not be considered a medical, nutritional, or fitness recommendation.

Results & Insights

  • Compared multiple regression algorithms, including Linear Regression, Polynomial Regression, Ridge, Lasso, KNN, Decision Tree, and Random Forest.
  • Random Forest Regressor was selected as the final model based on its stronger test performance.
  • The model captures non-linear relationships between personal and exercise-related features and calories burned.
  • The trained model was successfully integrated into a Streamlit web application for real-time calorie-burn prediction.
  • Users can enter their personal and exercise details and receive an estimated number of calories burned.

Streamlit Deployment

The trained regression model was integrated into a Streamlit application. The application provides a simple interface where users can enter exercise values and view the predicted calorie expenditure.
